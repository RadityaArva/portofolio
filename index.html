01 — About Me

Hi, I’m Raditya.

I'm a Software Engineering graduate from SMK Semen Gresik, working across three connected fields: web development, UI/UX design, and cybersecurity. To me, these aren't separate skills a great design means little on a vulnerable system, and secure code means little with a poor user experience.

My hands-on foundation comes from a 9-month internship at PT Petrokimia Gresik in the IT Network & Data Operations division, where I worked on EUC asset data audits, network monitoring, internal website deployment, and IT incident resolution. That experience shaped my interest in system security and network infrastructure. On the design side, I'm comfortable moving from Figma wireframes to responsive, production-ready frontend code.

Best fit for

  • ▸ UI/UX redesigns from brief or wireframe to responsive frontend
  • ▸ Basic web application security checks and system hardening
